## Layman Summary

Tests whether nudging a small code model's internal activations makes it invent more varied, still-correct path-search algorithms than raising temperature or prompting does; it does not.

## Full Summary

INFLUENCE ARM, Qwen2.5-3B-Instruct, one HF engine for every condition (per-sample seeded inverse-CDF sampler, code-block stop, 768 max tokens). Tasks: T1 open path search, T3 weighted shortest path. Correctness = sandboxed oracle on 50 fixed graphs (all must pass); idea label = AST classifier (audited vs blind gpt-4.1-mini judge on 200 programs: agreement 0.715, kappa 0.68). Baseline T=0.7 n=300: T1 BFS 205/DFS 80 (pass 0.70), T3 Dijkstra 225/BFS-relax 71 (pass 0.37); menus T1={bfs,dfs}, T3={dijkstra,bfs}. Probes at gen1..8 are at chance (boilerplate opening; algorithm name first appears at median token 23.5/46.5), so fallback F4 was used: probe on mean(gen1..32) (bal acc ~0.65-0.69 vs shuffled 0.42), hook window prompt-final+gen1..64, band layers 29-31. Sweep n=150/setting (controls 75): H-probe/H-dim (5 calibrated alphas), A3 rank-1 projection + LEACE, A4 cross-task unusualness direction, matched-norm random controls, temperature 1.0-2.0, top-k, 'new'/'novel2000' prompts, ban-top-3, generate-then-select; held-out re-draw (seeds 1000..1099) for selected settings. RESULT: no internal knob survives the pre-registered rules -> 'prompting ceiling'. Pooled pass/idea-entropy: baseline 0.53/1.05; ban-top-3 0.43/1.59 (best eligible, tops entropy front); gen-then-select 0.26/2.56; best H-dim 0.57/1.06 (held-out entropy ratio vs best temperature 0.93 T1, 1.20 T3; needed >=2; CI vs random direction includes 0); H-probe has no setting at matched pass rate; A4 dial not monotone (Spearman 0.49 T1, -0.26 T3) although its readout transfers (AUROC 1.0); judge-confirmed novel-and-correct share = 0 in every condition (all 70 rule-'other' passing programs were known algorithms), so A3 fails despite LEACE erasing idea decodability offline (T3 0.88->0.35). Mechanistic finding: H directions SELECT rather than flatten (H-dim a=0.224 turns T1 into DFS 145/150 at unchanged pass 0.68) - internal knobs give controllable choice among known ideas, not novelty; random matched-norm directions raise entropy about as much as targeted knobs. Noise floor: batch-composition re-run flips 11-17% of labels. Independent re-derivation (verify_headline.py: own oracle runner 147/147 agreement, coarse classifier 97%, pandas recomputation) reproduces headline numbers; placebo CIs include 0.
